# SentinelSys – Intelligent Linux Monitoring Platform

### An end-to-end Linux system monitoring and analytics platform that collects, analyzes, and visualizes system performance data using Python and data science techniques.

---

## 📌 Overview

**SentinelSys** is an intelligent Linux monitoring and analytics platform built to simulate real-world infrastructure monitoring. It collects real-time system metrics, stores them efficiently, and transforms raw data into actionable insights using data analysis and machine learning workflows.

Designed as a comprehensive, self-paced project, SentinelSys integrates:

- **Python scripting**
- **Linux automation**
- **System-level monitoring**
- **Data engineering**
- **Visualization dashboards**
- **Machine learning analytics**

---The project integrates **Linux system monitoring**, **Python-based data engineering**, and **data science analytics**, demonstrating how low-level system data can support intelligent decision-making.

---

## 🎯 Project Objectives
- Collect real-time Linux system metrics  
- Automate monitoring using Python and Bash  
- Build structured datasets for analytics  
- Perform exploratory data analysis (EDA)   
- Visualize system health and performance trends  

---

## 🧠 Key Features

- **Real-time System Monitoring**
  - CPU usage, memory utilization, disk usage, load average, and process statistics
- **Automated Data Logging**
  - Lightweight Python and Bash scripts for continuous metric collection
- **Efficient Data Engineering**
  - Clean, structured, analysis-ready datasets
- **Exploratory Data Analysis (EDA)**
  - Trend analysis, correlations, and system behavior profiling
- **Visual Insights**
  - Interpretable plots and dashboard-style visualizations

## 🛠️ Complete Technology Stack

### 🖥️ Operating System
- Linux (Ubuntu / Debian-based distributions recommended)

### 🧑‍💻 Programming & Scripting Languages
- **Python** – Core logic, data collection, analysis, and machine learning
- **Bash (Shell Scripting)** – Linux automation and task scheduling

### 📊 Data Science & Analytics
- **Jupyter Notebook** – Interactive analysis and experimentation
- **pandas** – Data manipulation and preprocessing
- **numpy** – Numerical computations
- **matplotlib** – Data visualization
- **seaborn** – Statistical data visualization
- **scikit-learn** – Machine learning models and evaluation

### 🧠 System Monitoring & Data Collection
- **psutil** – System and process monitoring
- **OS-level Linux utilities** – CPU, memory, disk, and process metrics

### 🗃️ Data Handling
- CSV-based structured logging
- Time-series style datasets for performance analysis

### 🔧 Development & Tooling
- **Git & GitHub** – Version control and collaboration
- **GitHub Issues & Pull Requests** – Project management
- **GitHub Actions** – Workflow automation (optional / extendable)

🛠️ Technologies and Languages

The project is built predominantly as an analytical platform, leveraging the following language distribution:

🚀 Getting Started

1️⃣ Clone the Repository 

git clone [https://github.com/Abhishek08Mishra/SentinelSys-Intelligent-Linux-Monitoring-Platform.git](https://github.com/Abhishek08Mishra/SentinelSys-Intelligent-Linux-Monitoring-Platform)

cd SentinelSys-Intelligent-Linux-Monitoring-Platform

2️⃣ Start System Metric Collection Run the logging script to begin harvesting real-time Linux performance data,.

python system_logger.py

3️⃣ Automate Monitoring Tasks Utilize the shell script for automated system tasks and monitoring routines,.

bash script_sample.sh

4️⃣ Run Data Analysis & Machine Learning Open the Jupyter Notebook to process the collected metrics and generate insights,.

jupyter notebook linux_sys_analysis_EDA.ipynb
